## 2025-01-23 - Build Environment Mismatches and JUnit Conflicts
**Learning:** The project is configured for Java 25 but the environment runs Java 21. Attempting to force Java 21 via `pom.xml` modifications revealed compilation issues with Lombok and missing modules (`jdk.incubator.vector`). Additionally, running tests exposed a `NoSuchMethodError` in JUnit (`ExtensionContext$Store.computeIfAbsent`), indicating a mismatch between `junit-platform-engine` (1.9.3) and `junit-jupiter` (5.11.3).
**Action:** When working in restricted environments with version mismatches, prioritize static analysis and careful code review over executing full test suites if the environment cannot be easily fixed. Be aware of `spring-boot-starter-test` dependency hierarchy potentially pulling older JUnit platform versions.
